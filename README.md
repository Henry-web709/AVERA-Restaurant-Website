# AVERA Restaurant Website

### Fine Dining. Extraordinary Moments.

## About the Project

AVERA is a luxury restaurant website designed to showcase a combination of Nigerian and international cuisine.

The website provides visitors with information about the restaurant, its menu, dining experience, contact details and table reservation options.

The project was developed as part of the New Horizon Web Development Project.

## Project Objectives

- To create an attractive and user-friendly restaurant website.
- To showcase Nigerian and continental dishes.
- To provide customers with contact information.
- To allow customers to submit table reservation requests.
- To develop a responsive website that works on different devices.

## Technologies Used

- HTML5 – For the structure of the website.
- CSS3 – For styling, layout and responsiveness.
- JavaScript – For form validation and interactivity.

## Website Features

1. Home Page – Introduces AVERA Restaurant.
2. About Us – Provides information about the restaurant.
3. Menu Section – Displays Nigerian dishes, continental meals, desserts and drinks.
4. Experience Section – Highlights the restaurant's dining experience.
5. Reservation Form – Allows customers to submit table reservation requests.
6. Contact Section – Provides contact details and a message form.
7. Footer – Contains quick links and social media links.

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html.
4. Run the website using Live Server or a web browser.

## Responsive Design

The website uses CSS Flexbox, CSS Grid and media queries to adapt to different screen sizes, including desktops, tablets and mobile phones.
